# nbt-tree-format

把 NBT 层级信息（源码定义、NBT 文件、dump、日志或口述）输出为「类型符号 + 加粗名称 + 英文冒号 + 说明」的树形 Markdown 大纲。完整规则、多态写法与全部示例见 [SKILL.md](SKILL.md)。

## 效果

```md
`{}` **tag**: 父标签。\
 └─ `{}` **Fireworks**: 烟花火箭的参数。\
     ├─ `B` **Flight**: （可选，默认0）烟花火箭的飞行时间（火药数）。\
     └─ `[]` **Explosions**: （可选）每次爆裂的数据。\
         └─ `{}`: 一个烟火样式。\
             └─ `B` **Type**: （可选）爆裂形态：0 小型球状、1 大型球状、2 星形、3 苦力怕状、4 喷发状。\
```

## 要点

- 每行 `类型符号` → `**名称**` →（可选条件段）→ `: ` → 说明；分支行无名称，用 `↳` 取代 `├─`/`└─`。
- 类型：`{}`、`B`、`S`、`I`、`L`、`F`、`D`、`T/F`、`""`、`[]`、`[B]`、`[I]`、`[L]`；可并列，如 `{}` `[]` `""`。
- 缩进：根顶格，子列 = 父列 + 4（父是分支行时 +3）；`│` 贯穿有后续兄弟的祖先。
- 只有 `{}`/`[]` 有子行，空集合写 `` `{}`: （空） ``；可能不存在的标「（可选）」，有默认值写「（可选，默认X）」。
- 多态：值类型多变用 `↳` 分支行；成员集合变化用「（n 选一，判别键 X，成员平铺本级）」+ 条件段；复杂或复用的条件写成命名条件 `条件「名称」`。
- 混合元素、递归、开放键集、特殊豁免等写法见 SKILL.md。
- 整段输出包进 `` ```md `` 代码块（树外分支小节同样），每行末尾保留 `\`。

## JSON / JSON-NBT / SNBT

三种结构各自单独成块，首行写标记（大小写不敏感），根从第二行开始：

- `「JSON」`：JSON 六类型 `{}`、`[]`、`""`、`N`、`T/F`、`null`。
- `「JSON-NBT」`：用 NBT 类型符号（解析后是强类型 NBT）。
- `「SNBT」`：用 NBT 类型符号，直接按 NBT 规则写。

## 辅助检查

```bash
python check_tree_format.py 报告.md -o check-report.txt
```

位置参数可给多个文件/目录（目录递归找 `*.md`）；`--json`、`--encoding`、`--ignore-non-tree`、`--quiet`、`--exit-zero` 见 `--help`。

## 安装

复制到 agent 的 skills 目录，或直接 `git clone` 到该目录：

```powershell
Copy-Item -Recurse -Force .\nbt-tree-format "$env:USERPROFILE\.agents\skills\nbt-tree-format"
```
