# nbt-tree-format

把 NBT 层级信息（源码定义、NBT 文件、dump、日志或口述等）输出为「类型符号 + 加粗名称 + 中文冒号 + 说明」的树形 Markdown 大纲。

## 效果

```md
`{}` **tag**：父标签。\
 └─ `{}` **Fireworks**：烟花火箭的参数。\
     ├─ `B` **Flight**：（可选，默认0）烟花火箭的飞行的时间，单位为“火药”（即表现为和工作台上合成烟花火箭时所用的火药数相等）。\
     └─ `[]` **Explosions**：（可选）包含烟花火箭每次爆裂的数据，元素为复合标签。\
         └─ `{}`：一个烟火样式。\
             ├─ `[I]` **Colors**：（可选）表示爆裂时的粒子颜色。\
             └─ `B` **Type**：（可选）爆裂时的形态。\
```

多态键（同一个键在不同判别值下结构不同）用分支行表达，不伪造一层子节点：

```md
 ├─ `{}` `""` **contents**：（可选，三选一，判别键 `action`）悬停内容。\
 │   ↳ `action`=`show_item`：物品对象，也可只写物品 ID 字符串。\
 │       ├─ `""` **id**：物品 ID。\
 │       └─ `I` **count**：（可选，默认 1）数量。\
```

## 规则摘要

- 每行：`类型符号` → `**名称**` → `：` → 说明；名称加粗，用中文冒号。多态键的取值分支例外：分支行不写类型符号与名称，写「`判别键`=`值`」+ `：` + 说明。
- 类型符号：`{}` compound、`B` byte、`S` short、`I` int、`L` long、`F` float、`D` double、`T/F` boolean、`""` string、`[]` list、`[B]`/`[I]`/`[L]` 数组；一个字段可能对应多个类型时并列写，如 `{}` `[]` `""` **tag**；分支行没有类型符号。
- 缩进：根节点顶格，第一层符号前 1 个空格，每深一层加 4 个空格；祖先为 `├─` 的列位画 `│` 并贯穿其子树；分支行用 `↳` 取代 `├─`/`└─`，占同一列位。
- 只有 `{}` 和 `[]` 有子行；空集合也必须给出子行，写作 `` `{}`：（空） `` 或 `` `[]`：（空） ``。
- 可能不存在的节点，说明开头用「（可选）」，不加逗号。
- 混合元素列表用「（混合元素）」标注，元素类型与作用写在展开的子行，父级只描述列表作用。
- 递归结构用「（递归）」标注，并指明可递归的父节点，只展开一层。
- 多态键（同一键多种形态）：分支扁平时（分支数 ≤ 3、分支内无容器、分支部分合计 ≤ 12 行）用分支行 `↳`；否则树里只留一行并指向树外，树外单开「#### <键名> 分支」小节。同一个键只用一种写法，不得混用。
- 根可以放在任意位置时不写名称（`` `{}`：根标签 ``）；根必须是指定字段名时才写（`{}` **tag**：父标签。）。
- 整体输出必须包进 ```md 代码块，以保留缩进。

完整规则见 [SKILL.md](SKILL.md)。

## 辅助检查

同目录的 `check_tree_format.py` 按本技能规则校验 Markdown 里的树块（缩进、竖线、分支行、子行、行尾 `\` 等）：

```bash
python check_tree_format.py 报告.md -o check-report.txt
```

位置参数给要检查的文件（也可以给目录，会递归找 `*.md`）；`-o/--output` 指定文本报告路径（省略则打印到终端），`--json` 另出一份 JSON。参数与规则名详见 [SKILL.md](SKILL.md) 的「辅助检查脚本」。

## 安装

把本目录复制到 agent 的 skills 目录下：

```powershell
Copy-Item -Recurse -Force .\nbt-tree-format "$env:USERPROFILE\.agents\skills\nbt-tree-format"
```

也可以直接 `git clone` 到该目录。
