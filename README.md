# nbt-tree-format

把 NBT 层级信息（源码定义、NBT 文件、dump、日志或口述等）输出为「类型符号 + 加粗名称 + 中文冒号 + 说明」的树形 Markdown 大纲。

## 效果

```md
`{}` **tag**：父标签。\
 └─ `{}` **Fireworks**：烟花火箭的参数。\
     ├─ `B` **Flight**：（可选，默认0）烟花火箭的飞行的时间，单位为“火药”（即表现为和工作台上合成烟花火箭时所用的火药数相等）。\
     └─ `[]` **Explosions**：（可选）包含烟花火箭每次爆裂的数据，元素为复合标签。\
         └─ `{}`：一个烟火样式。\
             ├─ `[I]` **Colors**：（可选）表示爆裂时的粒子颜色。\
             └─ `B` **Type**：（可选）爆裂时的形态。\
```

多态键（同一个键在不同判别值下结构不同）用分支行表达，不伪造一层子节点；分支行要写类型符号，子行只缩进 3 格：

```md
 ├─ `""` **action**：`show_text`、`show_item`、`show_entity` 之一。\
 ├─ `{}` `""` **contents**：（可选，三选一，判别键 `action`）悬停内容。\
 │   ↳ `{}` `""` `action`=`show_item`：物品对象，也可只写物品 ID 字符串。\
 │      ├─ `""` **id**：物品 ID。\
 │      ├─ `I` **count**：（可选，默认 1）数量。\
 │      └─ `{}` **components**：（可选）物品组件补丁。\
 │          └─ `""` **（组件 ID）**：文本类组件此处是 JSON 字符串。\
```

成员多态（同一对象骨架、出现哪些成员随判别值变化，如 `type` 决定其余字段）不新增层级：多态行写「（n 选一，判别键 X，成员平铺本级）」，受控成员行写「（仅 X=值）」，判别键唯一可见时可简写「（仅 值）」：

```md
 ├─ `""` **type**：（三选一，判别键 `type`，成员平铺本级）`blank`、`styled`、`fixed` 之一；`blank` 无附加成员。\
 ├─ `{}` `""` **value**：（仅 `type`=`fixed`）固定显示组件（递归）。\
 ├─ `""` **color**：（仅 `styled`，可选）文字颜色。\
 └─ `""` **font**：（仅 `styled`，可选）字体资源位置。\
```

## 规则摘要

- 每行：`类型符号` → `**名称**`（或分支行的 `` `判别键`=`值` ``）→ `：` → 说明；名称加粗，用中文冒号。
- 类型符号：`{}` compound、`B` byte、`S` short、`I` int、`L` long、`F` float、`D` double、`T/F` boolean、`""` string、`[]` list、`[B]`/`[I]`/`[L]` 数组；一个字段可能对应多个类型时并列写，如 `{}` `[]` `""` **tag**；分支行也写类型符号，多种并列写一行。
- 缩进：根节点顶格，子列 = 父列 + 4（父是分支行时 +3），第 1 层在列 1；祖先为 `├─` 的列位画 `│` 并贯穿其子树；分支行用 `↳` 取代 `├─`/`└─`，其子行 +3、再往下 +4。
- 只有 `{}` 和 `[]` 有子行；空集合也必须给出子行，写作 `` `{}`：（空） `` 或 `` `[]`：（空） ``。
- 可能不存在的节点，说明开头用「（可选）」，不加逗号；未设置时取默认值的写成「（可选，默认X）」；无法推断说明时写「（无说明）」。
- 混合元素列表用「（混合元素）」标注；父级只描述列表作用。能统一描述时元素类型并列写一行；需要展开字段时按类型分行（一行一个类型）并照常展开 `{}` 字段；同一列表只用一种写法。
- 递归结构用「（递归）」标注，并指明可递归的父节点，只展开一层。
- 多态键（同一键多种形态）：默认树内用分支行 `↳`（分支里允许容器与子树，子行 +3、再往下 +4）；只有单块预计超过约一屏（80–100 行）或变体各自很大时才树外单开「#### <键名> 分支」小节（也在 ```md 块内，开头写明判别键，逐条写「- 类型符号 `判别键`=`值`：说明」）。同一个键只用一种写法，不得混用。
- 成员多态（同一对象骨架、成员集合随判别值变化，如 `type` 决定其余字段）：不新增层级，多态行写「（n 选一，判别键 X，成员平铺本级）」，受控成员行写「（仅 X=值）」或简写「（仅 值）」，无附加成员的取值在判别键行写明；同一对象不得与 `↳` 分支混用。
- 根可以放在任意位置时不写名称（`` `{}`：根标签 ``）；根必须是指定字段名时才写（`{}` **tag**：父标签。）。
- 整体输出必须包进 ```md 代码块（树外分支小节同样如此），以保留缩进。

完整规则见 [SKILL.md](SKILL.md)。

## 辅助检查

同目录的 `check_tree_format.py` 按本技能规则校验 Markdown 里的树块（缩进、竖线、分支行、子行、行尾 `\` 等）以及树外分支小节块：

```bash
python check_tree_format.py 报告.md -o check-report.txt
```

位置参数给要检查的文件（也可以给目录，会递归找 `*.md`）；`-o/--output` 指定文本报告路径（省略则打印到终端），`--json` 另出一份 JSON，`--encoding` 指定编码（默认 `utf-8`），`--ignore-non-tree` 跳过非树块，`--quiet` 只打印汇总行，`--exit-zero` 出问题也返回 0。规则名与退出码见 [SKILL.md](SKILL.md) 的「辅助检查脚本」。

## 安装

把本目录复制到 agent 的 skills 目录下：

```powershell
Copy-Item -Recurse -Force .\nbt-tree-format "$env:USERPROFILE\.agents\skills\nbt-tree-format"
```

也可以直接 `git clone` 到该目录。
